📖 How to Play

Host: before you start

  1. Click Host Mode and set a PIN. Add, rename, or remove teams (2 to 10) and enter each team's rep name.
  2. Enter the Timer and Grammarian names in the bar below.
  3. Share the QR code, join link, or game code from the Invite players box (it appears when Host Mode is on). Players scan the code, tap the link, or type the code on the main page. Everyone must be in the same game.
  4. Get prompts into each team's pool. Either teams type topics live below, or you open Import Prompts for a Team and paste or upload a list for each team (one prompt per line, or a .csv file).
  5. Optional: add a few ⭐ Host wildcards from the same import box. Any team can draw them, and they never take a turn. Watch the Prompt Supply box to see which teams are running low.

Players: submit topics in secret

  1. Find your team's card near the bottom of the page.
  2. Type a fun impromptu question (150 characters max) and tap Add Topic.
  3. Only a running count shows. Topics stay hidden until one is drawn.

Running a round

  1. The stage shows which team speaks next. The host taps Draw Topic to pull a random topic written by a different team.
  2. The Timer role picks 30s, 60s, 90s, or 2m, then taps Start Timer when the speaker begins. The clock turns gold, then red, as time runs out.
  3. The Grammarian types notes in the box and taps Save Note. All notes collect in the Grammarian's Report for one closing summary.
  4. Everyone except the speaker rates the speech on the five criteria (1 to 5) and taps Submit My Rating. Rate once per speaker.
  5. The host reviews the averages, then taps Apply to Scoreboard for the suggested points, or uses +1, +3, +5, or −1 to decide the score.
  6. Tap Next Turn. The used topic is retired and the next team is up.
Tips: Use Present Mode on the projector or shared screen to hide the setup panels. Only the host should press Draw Topic, Timer, Next Turn, and the score buttons, because those controls work on every device. To start a fresh game, tap New Game Code in the Invite players box.
